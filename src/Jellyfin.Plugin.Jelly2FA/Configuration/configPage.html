Jelly2FA

Sign-ins through the reverse proxy (DDNS/nginx) need the password followed directly by an emailed 8-digit code. Direct LAN/Tailscale sign-ins need the password only. API keys are not affected.

Quick Connect

Second step

The code is still only sent after a correct password and only works once, on the same device/app and from the same IP that requested it. Trade-off: whoever can read the user's mailbox (and copies the device details from the same network) can use a pending code without retyping the password. Password + code keeps working.

SMTP password

Stored in the plugin data folder (mode 0600), never shown again. The environment variable JELLY2FA_SMTP_PASSWORD overrides it.
